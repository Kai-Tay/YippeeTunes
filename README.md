# YippeeTunes - DAP 2024 Project
DAP is a project-oriented learning programme where mentees can learn through self-initiated projects in small groups and weekly theory sessions in tandem. Through mentorship, DAP aims to equip our associates with important data science knowledge and skills by creating a co-learning community.

## Libraries used
<ul>
  <li>Pandas</li>
  <li>Selenium</li>
  <li>Scikit-Learn</li>
  <li>matplotlib</li>
</ul>

## Final Model
Utilises Web Scrapping of Genres, Genre Clustering and Cosine Similarity to achieve model with our highest performance yet.
